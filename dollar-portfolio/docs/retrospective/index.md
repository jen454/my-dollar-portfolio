# 나의 달러 포트폴리오 — 서비스 회고

> 2026.06 기준 회고.  
> 토스 미니앱(WebView)으로 배포된 달러 환전 손익 계산기.

---

## 서비스 한 줄 설명

토스증권 달러 예수금의 **평균 환전단가**와 **투입 원화 대비 손익**을 계산해주는 도구.  
투자 조언 없음, 순수 계산기.

## 기술 요약

| 항목 | 선택 |
|------|------|
| 프레임워크 | React + Vite + TypeScript |
| 상태 관리 | Zustand |
| 플랫폼 | 토스 미니앱 (WebView) |
| 디자인 시스템 | TDS (Toss Design System) |
| 배포 | Vercel |
| 환율 API | 한국수출입은행 OpenAPI |
